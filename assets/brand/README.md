# 채널 띠 (릴스 기본 디자인)

세로 영상(릴스·숏츠)을 만들 때 검은 위·아래 띠를 깔고 **위 띠에는 영상 제목**, **아래 띠에는 채널명**을 모션그래픽으로 넣어요.
디자인은 시안 1 "스트로크 샤인"이에요(흰 글자 + 빨간 테두리, 글자가 하나씩 튀어나온 뒤 빛이 지나감). 코드는 `src/core/brandBand.ts`.

`brand.json` 으로 정해요.

| 키 | 뜻 |
|---|---|
| `enabled` | `false` 면 띠 없이 예전처럼(흐린 배경) 만들어요 |
| `purposes` | 띠를 넣을 용도. 기본 `["short"]`(세로만). 가로 게시물(`post`)에는 넣지 않아요 |
| `channelKo` | 아래 띠 위쪽 빨간 이름표(한글 채널명). 비우면 이름표 없이 |
| `channelEn` | 아래 띠의 큰 영문 채널명. 비우면 이름표만 |
| `accent` | 테두리·이름표 색 |

- 위 띠 제목은 편집 대본의 제목(승인 때 `--title "…"` 로 바꿀 수 있어요)이에요. 길면 한 줄에 들어가게 글자가 작아져요.
- 영상은 화면 폭을 다 써요. 가로 영상은 자르지 않고, 세로 영상은 가운데 800px(1920 기준)만 보여 줘요.
- 띠를 쓰면 훅 질문·소개 줄·소제목은 영상 안쪽 위에, 자막은 영상 안쪽 아래에 놓여요.
- 글꼴: Black Han Sans, Anton (둘 다 SIL Open Font License, `@fontsource` 패키지).
