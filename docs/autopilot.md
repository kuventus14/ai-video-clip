# 영상만 넣으면 자동 편집 + 업로드 (autopilot)

폴더에 영상을 넣으면 맥이 알아서 릴스로 편집하고, 켜 두었으면 유튜브 숏츠·인스타그램 릴스에도 올려요.
편집 승인 단계는 없어요. 제목은 AI 가 영상을 보고 지어요(화면 위 제목 띠와 업로드 제목에 같이 써요).

## 1. 켜기 (한 번만)

앱 설치가 끝난 저장소 폴더에서:

```bash
npm run autopilot -- install
```

- 홈 폴더에 `릴스 자동편집` 폴더가 생기고, 바탕화면에 바로가기가 생겨요.
- 맥을 켜고 로그인하면 저절로 돌아가요. 터미널은 닫아도 돼요.
- 끄기: `npm run autopilot -- uninstall`
- 맥이 잠자기 중이면 편집하지 않아요. 깨어나면 이어서 해요.

자동 실행 없이 지금 터미널에서만 돌리려면 `npm run autopilot`(Ctrl+C 로 멈춤),
지금 넣어 둔 영상만 처리하고 끝내려면 `npm run autopilot -- once` 예요.

## 2. 폴더

| 폴더 | 하는 일 |
|---|---|
| `넣기` | 여기에 영상을 넣어요. 복사가 끝나고 몇 초 뒤에 편집을 시작해요 |
| `완성` | 편집된 영상 `원래이름_릴스.mp4` 가 생겨요. 업로드가 실패하면 옆에 `_업로드실패.txt` 가 생겨요 |
| `원본` | 편집이 끝난 원본을 옮겨 둬요(두 번 편집하지 않게) |
| `실패` | 편집하지 못한 원본과 `_오류.txt`(이유)를 둬요. 고친 뒤 다시 `넣기`에 넣으면 돼요 |
| `레퍼런스` | 여기에 레퍼런스 영상 하나를 넣어 두면 모든 영상을 그 스타일로 편집해요 |
| `.작업` | 작업 기록(`autopilot.log`)과 영상별 `report.json` (숨김 폴더) |

릴스·숏츠(세로)는 결과가 **항상 1분 이하**예요. 원본이 1분을 넘으면 AI 가 핵심만 골라 1분 이하로 줄이고, 1분 이하면 길이는 그대로 두고 편집만 해요.

## 3. 설정 (`설정.json`)

처음 켤 때 기본값으로 만들어져요. 텍스트 편집기로 고치면 다음 영상부터 바로 적용돼요.

- `edit.purpose`: `short`(세로 릴스·숏츠, 기본) / `post`(가로) / `auto`
- `edit.audio`: `voice`(소음 줄이고 목소리 크기 맞춤, 기본) / `original`
- `edit.bgm`: 배경음악 곡 id (기본 `null` = 없음), `edit.sfx`: `on`/`off`
- `edit.reference`: 레퍼런스 링크(유튜브·인스타). 비우면 `레퍼런스` 폴더의 영상을 써요
- `edit.description`: 모든 영상에 공통인 한 줄 설명(예: "골프 레슨 영상")
- `upload.caption`: 올리는 글. `{title}` 자리에 AI 제목이 들어가요. 해시태그는 유튜브 태그로도 써요
- `upload.youtube.enabled` / `upload.instagram.enabled`: 업로드 켜기(기본 꺼짐)
- `upload.youtube.privacy`: `private`(기본) / `unlisted` / `public`
- `upload.youtube.title`: 유튜브 제목(기본 `{title} #shorts`)

## 4. 유튜브 연결 (한 번만, 약 10분)

1. https://console.cloud.google.com 에서 새 프로젝트를 만들어요.
2. **API 및 서비스 → 라이브러리**에서 **YouTube Data API v3** 를 찾아 **사용**을 눌러요.
3. **OAuth 동의 화면(Google 인증 플랫폼)**: 사용자 유형 **외부**, 앱 이름은 아무거나, 내 이메일을 넣어요.
   그다음 **게시 상태를 '프로덕션'으로** 바꿔요. '테스트' 상태로 두면 7일마다 로그인이 풀려요.
4. **사용자 인증 정보 → 사용자 인증 정보 만들기 → OAuth 클라이언트 ID → 데스크톱 앱**으로 만들고 JSON 을 내려받아요.
5. 터미널에서:
   ```bash
   npm run connect -- youtube --client ~/Downloads/client_secret_XXXX.json
   ```
   브라우저가 열리면 채널 계정으로 로그인해요. "확인되지 않은 앱" 경고가 나오면 **고급 → (앱 이름)(으)로 이동**을 눌러요(내가 만든 앱이라 괜찮아요).
6. `설정.json` 에서 `upload.youtube.enabled` 를 `true` 로 바꿔요.

**알아 둘 점**
- 구글 심사를 받지 않은 프로젝트로 올린 영상은 **비공개로 잠겨요**(공개로 설정해도). 올라간 뒤 YouTube 스튜디오에서 직접 공개로 바꾸거나,
  [YouTube API 감사 신청](https://support.google.com/youtube/contact/yt_api_form)을 해서 승인받으면 바로 공개로 올라가요.
- 무료 할당량으로는 하루에 영상 약 6개까지 올릴 수 있어요.

## 5. 인스타그램 연결 (한 번만, 약 10분)

1. 인스타그램 앱 **설정 → 계정 유형 및 도구 → 프로페셔널 계정으로 전환**(크리에이터 또는 비즈니스).
2. https://developers.facebook.com 에서 **앱 만들기** → 사용 사례 **Instagram API(Instagram에서 메시지 및 콘텐츠 관리)** 를 골라요.
3. 앱 대시보드 **Instagram API → Instagram 비즈니스 로그인으로 API 설정**에서 **액세스 토큰 생성 → 계정 추가**로 내 인스타 계정에 로그인해요.
   (계정이 안 보이면 **앱 역할 → 역할 → Instagram 테스터**에 내 계정을 추가하고, 인스타 앱 **설정 → 웹사이트 권한 → 앱 및 웹사이트 → 테스터 초대**에서 수락해요.)
4. 나온 토큰을 복사해서:
   ```bash
   npm run connect -- instagram --token 복사한토큰
   ```
5. `설정.json` 에서 `upload.instagram.enabled` 를 `true` 로 바꿔요.

**알아 둘 점**
- 토큰은 60일이면 만료되는데, 30일이 지나면 업로드할 때 자동으로 연장해요. 두 달 넘게 한 번도 올리지 않으면 4번을 다시 해요.
- 내 계정에만 올리는 용도라 Meta 앱 심사는 필요 없어요.

연결 상태 확인: `npm run connect -- status`
열쇠(토큰)는 `~/.config/autoframes/upload.json` 에 나만 읽을 수 있게 저장돼요. 저장소나 자동편집 폴더에는 들어가지 않아요.
