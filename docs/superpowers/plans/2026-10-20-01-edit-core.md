# 영상 자동 편집 — 편집 코어 구현 계획 (Plan 1/3)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 영상 1개(+선택 레퍼런스·설명·참고 요청)를 넣으면, 용도(게시물 가로 / 릴스·숏츠 세로)에 맞게 컷·자막·제목 카드·리프레임을 적용해 hyperframes로 렌더하고, 검수(자막·화질·오디오·구도)를 통과시킨 mp4와 리포트를 내는 **CLI**를 만든다. 화면(웹앱)은 Plan 2, 업로드는 Plan 3.

**Architecture:** `src/core/*` 의 작은 모듈(입력 이해 → 용도 판별 → 레퍼런스 분석 → 요청 해석 → 컷·리프레임 계산 → hyperframes 프로젝트 생성·렌더 → 검수)을 `pipeline.ts` 가 순서대로 부르고, `src/cli/edit.ts` 가 이를 감싼다. 외부 도구(ffmpeg·whisper-cli·hyperframes·yt-dlp·Swift Vision)와 LLM(`claude -p`)은 전부 주입 가능한 얇은 래퍼 뒤에 둬서 가짜로 갈아끼워 시험한다.

**Tech Stack:** Node 24 + TypeScript(ESM), Vitest, tsx, zod, `@fontsource/noto-sans-kr`. 외부: ffmpeg/ffprobe 9.0.2, `hyperframes` 0.8.181, `whisper-cli`(모델 `~/.cache/hyperframes/whisper/models/ggml-small.bin`), `yt-dlp`, Swift(Vision, `swiftc`), `claude -p`(로그인 방식, 선례 `~/ai-staff/lib/claude.mjs`).

**Spec:** [`docs/superpowers/specs/2026-10-20-video-autoeditor-design.md`](../specs/2026-10-20-video-autoeditor-design.md) — 실행자는 계획과 설계 문서를 함께 읽는다. 위치: `~/Desktop/video-autoeditor`.

## Global Constraints

- 용도 값은 `'post'`(게시물 영상용, 캔버스 **1920×1080**) / `'short'`(릴스·숏츠용, **1080×1920**). 사용자가 고른 값이 자동 인식보다 **항상 우선**. (스펙 5-1)
- 레퍼런스의 **원본 영상·음원을 결과물에 쓰지 않는다.** 분석 후 다운로드한 레퍼런스 파일은 삭제한다. (스펙 3, 안티골)
- 검수 재작업 **최대 2회**. 그래도 남은 문제는 숨기지 않고 `report.json` 에 남긴 채 결과를 전달한다. (스펙 5)
- 카메라 워크·실사 합성 VFX는 만들지 않는다. BGM·효과음·하단바/콜아웃 오버레이는 **이 계획 범위 밖**(StyleSpec 에는 기록하고 `feasibility` 를 `'unsupported'` 로 표시, 계획 카드에서 정직하게 알림).
- 입력 영상 길이 **1초 이상 10분 이하**. 벗어나면 `InputError` (빌더 판단으로 정한 값).
- 모든 LLM 호출은 `src/core/llm.ts` 한 곳을 통과한다. 돈·크레딧이 드는 외부 호출(유료 API, 생성형 크레딧)은 이 계획에 없다.
- 사용자에게 보이는 문자열은 한국어. 모든 시간 값은 초(float). 정규화 좌표는 원점 좌상단, 0..1.
- hyperframes 규칙: standalone 루트(`<template>` 금지), 타임라인 1개(`window.__timelines["main"]`), **타이밍이 걸린 클립이 아니라 안쪽 래퍼를 트윈**, 자르기는 `data-media-start`/`data-duration`, `<video>` 에 `crossorigin` 금지, `<audio>` 는 `id` 필수, 이름 붙인 `font-family` 는 파일 안 `@font-face` 필수. 완료 판정은 `hyperframes check` 통과.
- 한글·공백이 든 파일명은 프로젝트 안에서 ASCII 이름(`source.mp4`)으로 복사해 쓴다.
- Git: 로컬 저장소만(Task 1 에서 `git init`), 작업마다 커밋, push 없음. 커밋 메시지 끝에 `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>`.
- 시험: 순수 함수는 단위 시험, 외부 도구는 `ensureFixtures()` 로 만든 합성 영상으로 시험. 실제 영상이 필요한 시험은 `INTEGRATION=1` 과 샘플 파일(`~/Desktop/롱아이언_릴스_편집본.mp4`, 1080×1920·56.8초·이미 자막이 구워져 있음)이 있을 때만 돈다.

## Review Focus

스펙이 암시하지만 아래 작업의 시험이 직접 확인하지 않으면 사용자가 겪을 가능성이 큰 입력 다섯 가지 (각 줄의 시험은 소유 작업에 들어 있다).

1. **오디오 트랙이 없는 영상** → 오류 없이 자막을 건너뛰고 리포트에 "음성 없음" 표시 (Task 4, 16).
2. **사람이 없는 영상(화면 녹화 등)을 세로로 크롭** → 중앙 크롭 + 리포트 경고 (Task 10, 11).
3. **정사각·4:5·세로→가로** 같은 비표준 비율 조합 → 크래시 없이 전략 선택 (Task 14).
4. **레퍼런스 링크가 막혔거나 너무 긴 경우** → 명확한 오류 종류, 조용한 대체 없음 (Task 7, 16).
5. **한글·공백·괄호가 든 파일명** → 조사·렌더까지 그대로 동작 (Task 2, 14).
