# 영상 자동 편집 — 배경음악·효과음 구현 계획 (Plan 4)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 계획 승인 화면에서 **배경음악(곡 고르기, 기본 없음)** 과 **효과음(켜기/끄기, 기본 끄기)** 을 고르면, 렌더된 영상에 음악을 목소리 밑에 깔고(목소리가 나올 때 자동으로 줄임) 컷·제목 카드 순간에 효과음을 넣은 결과를 만든다. 음원은 저작권 표시가 필요 없는 무료 음원만 앱에 내장한다.

**Architecture:** 소리는 hyperframes 프로젝트 **밖**에서 처리한다. `produceEdit` 이 렌더한 mp4 를 ffmpeg 한 번(`-c:v copy`)으로 다시 감싸 BGM·효과음을 섞고(`mix` 단계), 검수(`runQa`)는 섞인 파일을 본다. 음원은 `assets/sound/manifest.json` 한 개가 목록·출처·라이선스·측정 음량을 갖고, 목록 읽기·검증은 `src/shared/sound.ts`(화면·워커 공용), 위치 계산·측정·섞기는 `src/core/sound.ts`, 선택값은 작업 필드(`bgm_id`, `sfx_mode`)로 저장한다. 음원 파일 확보(Task 9)만 사용자 승인이 필요하고, 그 앞의 코드는 ffmpeg 가 만든 합성 소리로 시험한다.

**Tech Stack:** 기존(Node 24 + TypeScript, Vitest, zod, Next.js 16, node:sqlite) + ffmpeg 9(`sidechaincompress`·`amix`·`adelay`·`alimiter`·`ebur128`). 새 의존성 없음.

**Spec:** [`docs/superpowers/specs/2026-10-20-video-autoeditor-design.md`](../specs/2026-10-20-video-autoeditor-design.md) (47행: 레퍼런스의 음원은 결과물에 쓰지 않는다 / 40행: 음악·효과음은 범위 안). 위치: `~/Desktop/video-autoeditor`, 브랜치 `sound`(main 에서 분기).

## Global Constraints

- 배경음악·효과음은 **레퍼런스의 음원을 쓰지 않는다.** 앱에 내장한 무료 음원에서만 고른다. (스펙 47행)
- 허용 라이선스는 정확히 `'CC0'`, `'Pixabay License'`, `'Mixkit Free License'` 세 가지. CC-BY(저작자 표시 필요)·비영리 전용은 목록에 넣지 않는다. 모든 음원에 출처 주소(https)가 있어야 한다.
- 기본값은 **꺼짐**: `bgm = null`, `sfx = 'off'`. 이미 있는 작업과 "다른 버전" 복사본도 부모의 값을 그대로 이어받는다.
- 소리 처리는 hyperframes 구성을 바꾸지 않는다. 화면은 `-c:v copy` 로 다시 인코딩하지 않는다.
- 사용자에게 보이는 문자열은 한국어, 시간은 초(float), 음량은 LUFS·dBFS.
- **파일 내려받기는 항상 사용자 승인 뒤**(이름·출처·크기를 보여 주고 받는다). 승인 안 된 파일은 받지 않는다. API 키는 환경변수(`FREESOUND_API_KEY`)로만 쓰고 저장소·DB·로그·화면에 남기지 않는다.
- 경계: `app/ components/ src/shared/ src/db/ src/web/ src/ui/` 는 `src/core`·`src/worker` 를 가져오지 않는다(`tests/boundary.test.ts`). `src/shared` 는 `node:*`·zod·상대 경로만 쓴다. 그래서 목록 읽기(`loadCatalog`)는 `src/shared/sound.ts` 에 둔다.
- 음원 폴더는 `VAE_SOUND_DIR`, 없으면 `<실행 위치>/assets/sound`. 화면 서버 쪽에서 `process.cwd()` 를 쓸 때는 `src/web/context.ts` 처럼 `/*turbopackIgnore: true*/` 표시를 붙인다(안 붙이면 빌드가 프로젝트 전체를 추적한다).

## Review Focus

계획의 시험이 직접 확인하지 않으면 사용자가 겪을 가능성이 큰 다섯 가지 (각 시험은 소유 작업에 들어 있다).

1. **소리가 없는 영상**에 배경음악을 고름 → 오류 없이 배경음악만 담긴 소리가 된다 (Task 3).
2. **음악이 영상보다 짧거나**, 영상이 1~2초로 아주 짧음 → 반복·페이드가 길이를 넘지 않고 결과 길이 = 영상 길이(±0.1초) (Task 3).
3. **승인 뒤에 음원 파일이 지워지거나 목록이 깨짐** → 제작이 한국어 안내로 실패하고 작업이 "진행 중"에 갇히지 않는다 (Task 4, 5).
4. **컷이 아주 많은 영상**에 효과음을 켬 → 효과음 간격 2초 이상, 영상 끝을 넘는 효과음 없음 (Task 2).
5. **섞은 뒤 소리가 찌그러짐** → 결과의 최대 음량이 −0.9 dBFS 를 넘지 않고, 검수의 `audio-clipping` 이 뜨지 않는다 (Task 3, 5).

### Task 3: 소리 측정과 섞기

섞기 결정: 바탕 소리 = 영상의 소리(없으면 `anullsrc` 48k 스테레오). BGM = `-stream_loop -1` 입력 → `atrim=duration` → 크기 `volume=(목표 − bgm.lufs)dB`(목표 = 목소리 LUFS − 14, 목소리 측정값이 없으면 −22 LUFS) → 앞 `afade in`(min(1, 길이/4)초)·뒤 `afade out`(min(2.5, 길이/4)초). 목소리가 있으면 `sidechaincompress`(목소리를 키로)로 말할 때 음악을 줄인다. 효과음 = `adelay` + `volume`(최대 음량 목표 = min(−6, 목소리 peak − 8) − sfx.peakDb). 전부 `amix=normalize=0:duration=first` 뒤 `alimiter=limit=0.89`, 화면 `-c:v copy`, 소리 `aac 192k`, `-t` 영상 길이.

- [ ] **Step 1: 실패하는 시험.**
  - `buildMixArgs`(순수): 'BGM 만(소리 없음) → `sidechaincompress` 없음' · '목소리 있음 → `sidechaincompress` 있음' · '효과음 3개 → `adelay` 3개, 밀리초 반올림' · '`alimiter` 가 마지막 필터' · '`-c:v copy`' · '영상 1.5초 → 페이드 길이가 1.5/4 로 줄어든다, NaN·음수 없음' (포커스 2)

  - `mixSound` 실제 ffmpeg(합성 음원을 시험 안에서 `lavfi` 로 생성): 'BGM(2초)이 영상(5초)보다 짧아도 결과 길이 5±0.1초, 소리 있음' · '소리 없는 `silent` + BGM → 소리 생김, 길이 2±0.1초' (포커스 1) · '결과 peak ≤ −0.9 dBFS' (포커스 5) · '목소리 없는 구간의 BGM 크기 ≈ 목소리 LUFS − 14 (±3 LU)' (앞 2초만 사인파인 영상 + 일정한 소음 BGM, 뒤 구간을 잘라 `measureAudio`)
  - 'ffmpeg 가 실패하면 SoundError(한국어)'
