# 가로 → 세로: 자르지 않고 가운데 + 위아래 블러 띠 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 가로(또는 정사각·4:5) 영상을 세로 화면으로 만들 때 사람을 따라 **자르지 않고**, 영상을 가운데에 두고 위아래를 같은 장면을 흐리게 채운 배경으로 채운다. 제목·소개 줄·소제목·질문은 위쪽 띠에, 자막은 아래쪽 띠에 얹는다(사용자의 "릴스편집" 탭 결과와 같은 구성).

**Architecture:** 이미 있는 `blur-fill` 리프레임(세로→가로에서 쓰던 "가운데 + 흐린 배경")과 Plan 5 가 만든 띠 레이아웃(`overlayLayout`의 band 모드, 글자를 위·아래 띠에 얹음)을 연결한다. 연결 고리는 `chooseReframeMode`: 원본이 캔버스보다 넓을 때 'track'(사람 따라 자르기) 대신 'blur-fill' 을 고른다. 인물 추적·크롭 경로는 코드에 남지만 더는 고르지 않는다.

**Tech Stack:** TypeScript, hyperframes(HTML+GSAP 렌더), ffmpeg, vitest.

**Spec:** docs/superpowers/specs/2026-10-20-video-autoeditor-design.md (2026-10-20 에 "세로로 자를 땐 사람을 화면 중앙에"로 확정했던 것을 사용자가 2026-10-22 에 "자르지 말고 위아래 흐린 배경으로 채워 달라"로 바꿨다 — 이 계획이 그 변경이다). 선행: Plan 5(`2026-10-22-05-director.md`, 띠 레이아웃), Plan 1(blur-fill).

## Global Constraints

- 원본을 **자르지 않는다**: 가로 → 세로, 정사각 → 세로, 4:5 → 세로 모두 영상 전체가 보이게 가운데에 둔다(원본 비율은 같은 비율 ±0.05 이내면 그대로 `none`).
- 문구는 한국어 존댓말(~해요). 계획 카드는 실제 동작을 거짓 없이 말한다.
- 세로 → 가로(게시물용)는 지금 방식 그대로(가운데 + 양옆 블러)이고 바뀌지 않는다.
- 시험은 TDD. 화면에 보이는 것은 실제 렌더 프레임을 눈으로 확인한다(시험 통과와 보이는 것은 다르다).
- 인물 추적 코드(`person.ts`, 크롭 키프레임, 구도 검수)는 지우지 않는다 — 고르지만 않는다.

## Review Focus

1. **자막 위치 상·중·하 선택**과 띠: 위쪽 띠의 제목 묶음과 `top` 자막이 겹치거나, `bottom` 자막이 영상 위에 걸침(띠 밖).
2. **띠가 작은 비율**(4:3, 21:9, 3:4 에 가까운 4:5): 띠가 모자라면 글자가 영상 위에 얹히는데 읽히는가(Plan 5 의 띠 최소 크기 규칙).
3. **렌더 시간**: 영상 요소가 배경+앞 두 개이고 블러 필터가 들어가 긴 영상은 느려진다 — 실측해서 문서에 적는다.
4. **원본 해상도가 낮을 때**(720p 가로): 가운데 영상이 1080 폭에 맞춰 확대되는 정도와 검수 경고.
5. **훅 구간·컷 경계**에서 배경과 앞 영상이 같은 시각을 가리키는가(깜빡임·어긋남).
