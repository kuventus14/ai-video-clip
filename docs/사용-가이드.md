# 사용 가이드 — 릴스 자동 편집

영상을 폴더에 넣으면 릴스·숏츠로 자동 편집하고, Claude Code 에서 결과를 보고 **수락 / 거절 / 다시 만들기**를 고르는 흐름이에요.
설치는 [README 의 "Claude Code 로 한 번에 설치하기"](../README.md#claude-code-로-한-번에-설치하기) 또는 [맥 설치](install-mac.md) · [윈도우 설치](install-windows.md)를 보세요.

## 한눈에 보기

```
편집할 영상 ──(자동 편집)──▶ 완성 ──(Claude Code 에서 검토)──┬─ 수락 ──▶ 수락 폴더 + 레퍼런스 폴더
                                                          ├─ 거절 ──▶ 결과를 치움(원본은 보관)
                                                          └─ 다시 만들기 ──▶ 원본이 편집할 영상으로 돌아감
```

1. `릴스 자동편집/편집할 영상` 폴더에 영상을 넣어요(바탕화면 바로가기로 열 수 있어요).
2. 몇 분 뒤 `완성` 폴더에 `원래이름_릴스.mp4` 가 생겨요.
3. Claude Code 에서 **"검토해 줘"** 라고 하면 완성 영상을 하나씩 열어 주고 셋 중에서 고르게 해요.
4. 수락한 영상은 `수락` 폴더로 가고 `레퍼런스` 폴더에도 복사돼서, **다음 편집부터 그 스타일을 따라 해요.**

## 폴더

| 폴더 | 하는 일 |
|---|---|
| `편집할 영상` | 편집할 영상을 넣는 곳 |
| `레퍼런스` | 따라 할 영상. 가장 최근에 들어온 영상 하나를 따라 해요. 비어 있으면 기본 레퍼런스를 써요 |
| `완성` | 검토를 기다리는 결과. 편집에 실패하면 `_편집실패.txt` 에 이유가 있어요 |
| `수락` | 수락한 영상(나중에 자동 업로드할 영상) |

숨김 폴더 `.원본`(다시 만들기용 원본), `.기본 레퍼런스`, `.작업`(기록)은 건드리지 않아도 돼요.

## 편집 규칙 (기본값)

- **길이:** 릴스·숏츠는 항상 60초 이하. 원본이 1분 이하면 길이는 그대로 두고 편집만, 1분이 넘으면 AI 가 핵심만 골라 줄여요.
- **말 없는 장면:** 1분 넘는 원본을 줄일 때는 목소리 없는 장면을 모두 빼고 말끼리 이어요(음성 인식과 실제 소리 크기 둘 다로 확인).
- **소리:** 원본 소리 그대로 두고 크기만 알맞게(-16 LUFS) 맞춰요. 소음 제거(목소리 보정)는 꺼져 있어요.
- **화면:** 세로 1080×1920. 위 띠에 AI 가 지은 제목, 아래 띠에 채널명 "골프구조 GOLF STRUCTURE". 자막은 말에 맞춰 자동으로 들어가요.
- **레퍼런스:** `레퍼런스` 폴더의 가장 최근 영상 → 내가 정한 기본 레퍼런스 → 저장소에 들어 있는 기본 레퍼런스(`assets/default-reference`) 순으로 골라요.
- **업로드:** 기본으로 꺼져 있어요. 켜면 **수락할 때만** 유튜브·인스타에 올라가요.

## Claude Code 에서 말로 하기

| 이렇게 말하면 | 하는 일 |
|---|---|
| "검토해 줘" | 완성 영상을 하나씩 열고 수락·거절·다시 만들기를 물어봐요 |
| "다시 만들어 줘, 앞부분 설명을 살려 줘" | 고칠 점을 붙여 다시 편집해요 |
| "이 영상을 기본 레퍼런스로 해 줘" | 기본 레퍼런스를 바꿔요 |
| "이 영상 릴스로 편집해 줘" | 폴더 없이 앱 화면 흐름으로 편집해요(자막 확인 → 계획 승인 → 결과 확인) |

## 터미널 명령 (저장소 폴더에서)

```bash
npm run autopilot -- install                 # (맥) 로그인하면 자동으로 폴더를 지켜보게 등록
npm run autopilot                            # 지금 터미널에서 지켜보기(Ctrl+C 로 멈춤)
npm run autopilot -- once                    # 지금 넣어 둔 영상만 편집
npm run autopilot -- review                  # 검토를 기다리는 영상 보기
npm run autopilot -- accept "스윙_릴스.mp4"
npm run autopilot -- reject "스윙_릴스.mp4"
npm run autopilot -- redo "스윙_릴스.mp4" --note "고칠 점"
npm run autopilot -- set-default-reference ~/Desktop/기본.mp4
```

설정(`릴스 자동편집/설정.json`), 유튜브·인스타 연결은 [docs/autopilot.md](autopilot.md)에 있어요.

## 바꾸고 싶을 때

- **채널명·띠 색:** `assets/brand/brand.json` (`channelKo`, `channelEn`, `accent`, 띠를 끄려면 `enabled: false`)
- **해시태그·업로드 글:** `설정.json` 의 `upload.caption`
- **영상 설명(전문 용어 인식에 도움):** `설정.json` 의 `edit.description` (예: "골프 레슨 영상")
- **스타일이 한쪽으로 굳으면:** `레퍼런스` 폴더에서 마음에 안 드는 영상을 지워요

## 알아 둘 점

- 편집 한 편에 AI(Claude) 호출이 여러 번 들어가고, 로그인한 본인의 Claude 사용량에서 나가요. 영상은 내 컴퓨터 밖으로 나가지 않아요.
- 결과가 맞는지(내용, 말끝이 잘리지 않았는지, 자막 오타)는 사람이 보고 판단해야 해요. 그래서 검토 단계가 있어요.
- 레퍼런스 여러 개를 섞어 따라 하는 기능은 아직 없어요(가장 최근 하나).
- 자동 실행 등록은 맥만 돼요. 윈도우·리눅스는 `npm run autopilot` 을 켜 두세요.
