# autoframes — 레퍼런스처럼 자동 편집

영상을 올리면 분석·컷·자막·구도·소리·검수까지 하는 편집 엔진은 **저장소(ai-video-clip)의 앱** 안에 있고, 이 스킬은 그 앱을 **대화로 운전**하게 해 줘요. 화면(웹)으로 보고 싶은 사람에게는 앱을 켜 줄 수도 있어요(`http://127.0.0.1:4848`).

## 기본 규칙

- 모든 명령은 이 스킬의 도구로 해요: `node "<이 스킬 폴더>/scripts/autoframes.mjs" <명령>` (이 스킬을 불러올 때 알려 준 Base directory 가 스킬 폴더). 아래에서는 `AF` 라고 줄여 써요. 맥·윈도우·리눅스에서 같아요.
- **토큰을 아껴요.** 도구는 출력을 일부러 짧게 줘요. `analysis.json`·자막 대본·진행 기록 파일을 통째로 열지 마세요 — 필요한 건 `AF status`·`AF captions` 가 이미 요약해 줘요. 오래 걸리는 일은 `AF status <id> --wait` 한 번이면 돼요(끝날 때까지 알아서 기다려요).
- **사용자가 직접 정할 곳이 세 군데** 있어요(자막 확인 → 계획 승인 → 결과 확인). 거기서는 요약을 보여 주고 답을 받은 뒤에 넘어가요. 아무것도 안 묻고 끝까지 밀어붙이면 사용자가 원치 않는 영상이 만들어져요.
- AI 호출은 **사용자의 Claude 로그인 사용량**으로 나가고, 영상은 사용자의 컴퓨터 밖으로 나가지 않아요. 영상 한 편에 AI 호출이 여러 번 들어간다는 걸 처음에 한 번 알려 주세요.
- **업로드(유튜브·쇼츠·릴스·클립에 자동 게시)는 아직 없어요.** 결과 파일을 `AF result <id> --save <폴더>` 로 받아 사용자가 직접 올려요.

## 1. 시작하기

0. 이 스킬의 도구는 Node.js 로 돌아가요. `node -v` 가 22 이상이 아니면(없거나 낮으면) **먼저 Node.js 를 설치**해요(허락받고: 맥 `brew install node`, 윈도우 `winget install OpenJS.NodeJS`, 리눅스는 <https://nodejs.org>). 설치 뒤 새 터미널에서 이어가요.
1. `AF where` — 저장소 경로가 나오면 2번으로. **못 찾으면 설치부터** 도와요:
   - 사용자 OS 를 확인하고(`node -p process.platform`), `git clone https://github.com/kuventus14/ai-video-clip.git ~/ai-video-clip` 으로 받은 뒤, 저장소의 `docs/install-mac.md` / `docs/install-windows.md`(리눅스는 `README.md`)를 읽고 순서대로 따라 해요.
   - `brew`·`winget`·`apt` 같은 **시스템 프로그램을 설치하기 전에는 한 줄로 알리고 허락**을 받으세요. Claude 로그인·토큰은 사용자가 직접 해요(대신 입력하지 않아요).
   - 끝나면 저장소에서 `npm install` → `npm run setup`. `✗` 가 없어질 때까지 고쳐요(음성 인식 모델 465MB, whisper-cli, hyperframes, yt-dlp 등). 막히면 `references/troubleshooting.md`.
2. `AF app up` — 앱을 켜요(처음엔 화면 빌드로 몇 분). 이미 켜져 있으면 그대로예요. 끌 때는 `AF app down`.

## 2. 작업 흐름

| 단계 | 명령 | 사용자에게 |
|---|---|---|
| 올리기 | `AF new "<영상 경로>"` | 영상은 1초~10분, mp4·mov·m4v·webm·mkv·avi. 올라가면 길이·크기와 자동 인식한 용도가 나와요 |
| 시작 | `AF start <id> --purpose short\|post\|auto [--description "…"] [--reference <링크>]` | **용도**(릴스·숏츠 = 세로 / 게시물 = 가로; 직접 고른 값이 항상 우선), **영상 설명**(전문 용어 인식에 도움, 선택), **레퍼런스**(링크·파일, 없으면 분석 뒤 추천에서 골라요) |
| 기다리기 | `AF status <id> --wait` | 분석은 1분 영상 기준 30~40초 |
| **① 자막 확인** | `AF captions <id>` | 의심 단어(⚠)와 자막 없는 구간을 보여 주고 확인받아요. 고칠 게 있으면 `--save f.json` 으로 받아 f.json 을 고치고(줄마다 `start`·`end`·`text`) `AF plan <id> --captions-file f.json`. 규칙: 줄은 서로 겹치지 않고, 0.2초 이상, 160자 이하. 말이 인식되지 않은 영상은 줄을 직접 넣을 수 있어요 |
| 레퍼런스·계획 | `AF plan <id> [--reference <링크>\|--reference-file <파일>\|--reference none] [--request "참고할 부분"] [--purpose …]` | 추천 목록(`status` 에 나와요)에서 고르거나 링크·파일을 주거나, 없이 가도 돼요 |
| **② 계획 승인** | `AF status <id> --wait` 뒤 `AF approve <id> …` | "이렇게 이해했어요" 카드와 편집 구성(제목·훅 질문·소개 줄·속도)을 보여 주고 승인받아요. 옵션: `--captions auto\|off`(영상에 이미 자막이 있으면 off), `--position top\|middle\|bottom`, `--audio original\|voice`, `--bgm <곡id>\|none`(`AF sounds`), `--sfx on\|off`, `--quality draft\|looks\|delivery`, `--title "…"`, `--hook-question "…"` |
| 제작 | `AF status <id> --wait` | 영상 길이의 2~3배쯤 걸려요. 화면을 닫아도 계속돼요. `--wait` 가 끝나기 전에 도구 시간 제한이 오면 같은 명령을 다시 부르면 돼요 |
| **③ 결과 확인** | `AF status <id>` 뒤 `AF result <id> --save <폴더>` | 검수 결과를 보여 주고 **영상을 직접 열어 보게** 해요. 검수가 확인하지 않은 항목(소리가 어울리는지, 문구가 맞는지 등)은 사용자가 봐야 한다고 꼭 말해요 |
| 마무리 | `AF confirm <id>` / `AF plan <id> --request "고칠 점"` / `AF other <id>` / `AF remix <id> --bgm-gain N --sfx-gain N` | 확정(기록에 저장) · 수정 요청(이전 요청에 덧붙여 계획부터 다시 → 다시 승인) · 반대 용도 버전 · 소리 크기 |

실패하면 `AF status` 가 이유를 알려 주고 `AF retry <id>` 로 실패한 단계부터 다시 해요.

## 3. 소리(배경음악·효과음)

- 음악은 목소리보다 약 14 LU 작게 깔리고 말할 때 자동으로 더 줄어요. 효과음은 제목 카드와 컷이 바뀌는 곳에 들어가요.
- **크기는 AI 가 영상 내용(장르·말 비율·음악 분위기)으로 짐작해 정해요(−6~+4dB).** AI 는 소리를 직접 듣지 못해요 — 그래서 사용자가 들어 보고 `AF remix` 로 −12~+6dB 안에서 바꾸게 해요. 소리만 다시 섞으니 영상은 그대로고 1초 안팎이에요. `status` 의 "AI 추천"이 되돌릴 기준이에요.
- 소리 크기 기능이 생기기 전에 만든 작업은 다시 섞을 수 없어요(`status` 가 이유를 말해 줘요). 새로 만들면 돼요.
- 배경음악 파일은 저작권 때문에 저장소에 없어요. `AF sounds` 가 "음원 파일이 없어요"라고 하면 `assets/sound/README.md` 를 보고 넣거나 음악 없이 가요. `--audio voice`(목소리 또렷하게)는 `deep-filter` 설치가 필요해요(설치 안내에 있어요).

## 4. 정직하게 말해야 할 것

- 검수는 자막 정확도·화질·구도·길이·오디오를 자동으로 보지만 **"확인하지 않는 것"이 리포트에 따로 적혀 있어요.** 통과라고만 말하지 말고 그 목록을 전해요.
- 아직 엔진에 없는 것(강조 자동 인식·검토, 영상에 박힌 자막 읽기, 10분 영상을 1분으로 줄이기, 자동 업로드)을 요청받으면 **없다고 먼저 말하고**, `references/features.md` 의 진행 순서를 알려 줘요. 없는 기능을 되는 것처럼 흉내 내지 마세요.
- 방의 울림(리버브)은 줄지 않아요. 음악만 있는 영상은 인식기가 말을 지어내기도 해서 자막을 확인해야 해요.
- 윈도우·리눅스는 자동 시험으로 확인했지만 개발자가 손으로 써 본 건 맥이에요(`README.md` 의 "어디까지 확인했나").
