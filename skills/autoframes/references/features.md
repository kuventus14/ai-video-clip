# autoframes 기능 목록 · 한계 · 진행 순서

사용자에게 "뭐가 되나요?" 라고 물으면 여기서 답해요. **있음**은 지금 동작하는 것이고, **아직 없음**은 만들기로 했지만 엔진에 없는 것이에요.

## 있음

**입력·분석**
- 영상 1초~10분(mp4·mov·m4v·webm·mkv·avi). 용도를 자동 인식(세로·짧으면 릴스·숏츠용, 가로면 게시물용)하고 사용자가 고른 값이 항상 우선이에요.
- 음성 인식(whisper) — 영상 설명을 주면 전문 용어(예: 골프의 "롱아이언")를 더 정확히 받아 적어요. 설명을 인식기가 그대로 받아 적는 환각은 감지해서 힌트 없이 다시 인식해요.
- 영상 이해(요약·장르·제목 카드 문구), 비슷한 인기 영상 추천(yt-dlp 로 유튜브 검색, 최근 1년·조회수).

**레퍼런스** — 유튜브·인스타 링크나 파일을 분석해 스타일을 따라 해요(편집 속도, 훅, 자막 위치·크기·색, 제목 카드, 전환, 음악 유무). 레퍼런스가 없어도 기본 스타일로 만들어요. 이번 버전이 지원하지 않는 항목은 "이렇게 이해했어요"에 노란 줄로 알려 줘요.

**컷** — 긴 쉼, "음·어" 같은 군더더기, 다시 말한 부분(retake)을 정리해요. 사용자가 자막을 고쳐도 컷은 원래 인식 결과를 기준으로 해서 말이 잘리지 않아요.

**자막**
- 말하는 대로 넣고, AI 가 오타를 교정해요(원문과 너무 다르면 자동 적용 대신 제안만).
- 신뢰도 낮은 단어를 표시하고, 사용자가 **시간대별로 모든 줄을 고치고·추가하고·지우고·나누고·합칠 수** 있어요. 말이 없는 영상도 직접 넣을 수 있어요.
- 위치 top/middle/bottom(레퍼런스를 따름), 편집 감독이 정한 강조 단어는 노랑으로 나와요.

**구도** — 영상을 **자르지 않고** 가운데에 두고 위아래를 흐린(블러) 배경으로 채워요(16:9·1:1·4:5 → 세로). 사람을 따라 자르는 크롭은 쓰지 않아요.

**채널 띠(릴스 기본)** — 세로 영상은 블러 대신 검은 위·아래 띠를 깔고 위에 제목, 아래에 채널명(골프구조 GOLF STRUCTURE)을 모션그래픽(시안 1 "스트로크 샤인")으로 넣어요. 영상은 화면 폭을 다 쓰고, 세로 원본은 가운데 800px(1920 기준)만 보여 줘요. 설정은 `assets/brand/brand.json`.

**편집 감독(AI)** — 앞쪽 훅(핵심 장면 + 질문), 제목 카드, 소개 줄, 소제목, 질문·리액션, 속도(예: 1.1배), 덜 중요한 구간 빼기(최대 25%)를 짜요. 승인 단계에서 제목·훅 질문·소개 줄 문구를 사용자가 고칠 수 있어요.

**소리** — 원본 그대로 / 목소리 또렷하게(소음 제거 + 말소리 대역 정리 + −16 LUFS). 배경음악(분위기별 곡 + 미리듣기는 화면에서), 효과음(제목 pop·컷 whoosh), **AI 가 정하는 음악·효과음 크기 + 사용자가 결과를 들어 보고 −12~+6dB 로 조절(소리만 다시 섞기)**.

**검수** — 자막 오타·화질(비트레이트)·구도·길이·오디오를 보고, 심각하면 최대 2번 자동으로 다시 만들어요(화질 올리기·자막 다시 묶기·교정 적용). 리포트에는 **검수가 확인하지 않는 항목**이 따로 적혀 있어요.

**결과** — 확정(기록에 저장), 수정 요청(이전 요청에 덧붙여 계획부터 다시), 다른 버전(반대 용도로 새 작업), 파일 내려받기.

## 사용자가 정한 것들

- **릴스용이 먼저**예요. 가로↔세로는 자르지 않고 블러 띠로 채워요.
- 릴스(세로)에는 **항상 채널 띠**(위: 제목, 아래: 골프구조 GOLF STRUCTURE, 시안 1 스트로크 샤인)를 넣어요(2026-10-29).
- 릴스·숏츠(세로) 결과는 **항상 60초 이하**예요. 원본이 1분을 넘으면 AI 편집 감독이 핵심(설명·시범·결과)만 남겨 1분 이하로 줄이고, 그래도 넘치면 뒤쪽을 잘라 맞춰요. 1분 이하 원본은 길이를 그대로 두고(말 사이 쉼만 정리) 편집만 해요(2026-10-30). 가로 게시물은 상한이 없어요.
- 자막이 틀리면 **인식 모델을 키우는 대신 사용자가 자막을 고치게** 해요(더 큰 whisper 모델은 제외).
- 방 울림 제거는 한계가 있어서 하지 않아요. 소리 선택을 분석 앞으로 당기는 것도 제외예요.
- 소리 크기는 AI 가 정하고 사용자가 들어 보고 조절해요.
- 업로드는 **가장 마지막** 순서예요.

## 아직 없음 — 만드는 순서(쉬운 것부터, 사용자 확정)

1. ~~음악·효과음 AI 볼륨 + 결과 화면에서 조절~~ (완료)
2. **강조 자동 인식 + 사용자 검토·수정** — 강조할 부분을 AI 가 찾고 사용자에게 검토를 요청해요. (지금은 강조 색이 자막색과 같으면 안 보이고, 여러 단어 강조는 매칭이 안 돼서 강조가 눈에 안 띄어요.)
3. **영상에 박힌 자막·검은 띠의 글자 읽기**
4. **긴 영상(예: 10분, 말 많음)에서 핵심 장면만 골라 1분 릴스로 짜깁기** — 가장 어려워요. 먼저 말 많은 실제 영상으로 "장면 고르기"만 시험해 봐요.
5. **업로드**(유튜브·쇼츠·인스타 릴스·네이버 클립) — 코드 일부가 옛 브랜치에 있지만 실계정 확인(사용자 토큰)이 필요해요.

이 중 하나를 요청받으면 "아직 엔진에 없어요, 이 순서로 만들 예정이에요"라고 말하고, 만들어 달라고 하면 저장소(`docs/superpowers/plans/`의 계획 방식)에서 개발로 넘어가요.

## 한계(실측)

- 렌더·분석은 영상 길이의 2~3배쯤 걸려요(8GB 맥 기준). 무거운 작업은 한 번에 하나씩 돌려요.
- 소리가 영상 분위기와 어울리는지는 사람이 들어서 판단해야 해요.
- 음악만 있는 영상은 인식기가 "구독과 좋아요" 같은 말을 지어낼 수 있어요.
